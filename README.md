# Jane Doe(s)

A static exhibition collection of symbolic objects representing publicly sourced Jane Doe cases. Nothing is for sale.

No API services, credentials, accounts, payments, email delivery, uploads, or backend are included. Search and bookmarks operate in the visitor’s browser. Selected case summaries are generated and downloaded locally as printable HTML. Public and Private refer to the organizations involved in the cases, not access to private user data.

Source links open only when selected. Stories, symbolic-object notes, image credits and rights statements remain in the collection. Public pages and bundled assets remain downloadable; original third-party rights apply.
