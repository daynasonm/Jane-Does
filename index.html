About the collection

Jane Doe is a name used to protect an identity. This collection approaches those hidden lives through everyday things: a key, a wristband, a school bag.

Each object represents a case. Select one to read the story behind it.

Public — cases involving government bodies, public schools and public universities.
Private — cases involving private employers, insurers, organizations and individuals.

Symbolic objects, not case evidence. Sources are credited; allegations are not findings.

Explore and bookmark. Nothing is for sale.
